# 학교 채용 시스템

Next.js + TypeScript + Tailwind CSS로 시작한 수행평가 프로젝트입니다.

## 실행

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인합니다.

## 현재 구현
- 학교/외부 공고 분류
- 샘플 공고 검색 및 상세 펼치기
- 모바일 대응

모든 공고는 가상 샘플입니다. DB, 인증, 신청, 외부 API, Terraform은 아직 구현하지 않았습니다.

## 검사
```bash
npm run lint
npm run build
```
